The native cloud in a single binary.
Go. Rust. C++. Zero interpreter bloat.

Agents and bots can create a free account, get an API key, and test Enso, Kai, Zen models and the API Platform via hanzo.md (curl -fsSL https://hanzoskills.com/hanzo.md) — or run the open-source stack locally with skill.md.

Install
macOScurl -fsSL https://hanzo.sh | sh
Linuxcurl -fsSL https://hanzo.sh | sh
WSLcurl -fsSL https://hanzo.sh | sh

Then run hanzo. It signs you in through the browser, links this machine to Hanzo Tabs, asks once which coding agent is your favourite, adds Hanzo's tools to it, and launches it accelerated.

After that, hanzo launches your favourite, hanzo dev --claude|--codex|--cursor|--agy switches it, and hanzo -- -c continues the last conversation.

Or paste into your agentClaude Code, Codex, Cursor, Antigravity
